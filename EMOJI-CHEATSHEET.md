# Animal Crossing reaction stickers (`wuzzynizzy.github.io/wuzzynizzy/emoji/`)

All 88 Animal Crossing: New Horizons reaction PNGs live at stable root paths under `https://wuzzynizzy.github.io/wuzzynizzy/emoji/<name>.png` once `wuzzynizzy/wuzzynizzy.github.io` is live on GitHub Pages. Every file is a square transparent PNG with a crisp sticker outline (`500x500` to `1000x1000` for the original 32 stickers and `128x128` for the 56 reactions added from Nookipedia), so pass `width` and `height` whenever you embed one inline.

## Inline inside a GitHub README heading or sentence

GitHub Markdown strips CSS, so set `width`, `height`, and `align="absmiddle"` directly on the `<img>` tag:

```html
<h3>
  <img src="https://wuzzynizzy.github.io/wuzzynizzy/emoji/inspiration.png" width="24" height="24" alt="inspiration" align="absmiddle" />
  what i can do
</h3>
```

Inside a normal paragraph:

```html
hey from singapore <img src="https://wuzzynizzy.github.io/wuzzynizzy/emoji/greeting.png" width="20" height="20" alt="greeting" align="absmiddle" />
```

## Standalone sticker in Markdown or HTML

Plain Markdown (displays at native source size unless constrained by the container):

```markdown
![joy](https://wuzzynizzy.github.io/wuzzynizzy/emoji/joy.png)
```

Sized HTML (48x48 works cleanly for callouts and release notes):

```html
<img src="https://wuzzynizzy.github.io/wuzzynizzy/emoji/confetti.png" width="48" height="48" alt="confetti" />
```
