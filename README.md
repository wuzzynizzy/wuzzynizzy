hi, i'm nizzy.

I started coding at thirteen. Backend, mostly — databases, endpoints, the parts that don't have opinions about whitespace. I could make a service talk to another service all day. Then someone asked me to center a div and I had to lie down.

So for years I was the backend guy: strong on logic, allergic to CSS. Frontend felt like a completely different job held by people with better taste and worse sleep.

Then agents got good enough to close that gap, and I stopped treating my weak side as a personality trait.

## ⋆ the part that actually changed

I don't summon code and pray anymore. I write the spec first, and the spec is the product.

- **Spec-driven development.** User stories, constraints, acceptance criteria and the edge cases nobody wants to think about. Then the agent implements against a document instead of my vibes. If the spec is thin, the output is confidently wrong, and I only have myself to argue with.
- **Backend brain, borrowed frontend hands.** Years of thinking in schemas and failure modes turned out to be exactly what prompting needs. I know what breaks before it breaks; now I can also make it not look like a 2009 admin panel.
- **Integration is the whole job.** The plumbing between services, the auth boundary, the deploy step, the bit where the database and the design system have to agree. Agents made me fast there instead of careful.
- **Read the diff.** Still. Every time. An agent that ships in forty seconds and lies in two of them is not an engineer, it's a very fast intern, and I'm the one signing off.
- **Checks that can fail.** Broken anchor kills the build. Layout tested from 320 to 1440 pixels. A privacy scan before packaging. If a check can't fail, it's decoration.

The uncomfortable half: it writes the code I used to be proud of, faster, at 3am, without complaining. Frontend was the thing I was bad at, and then suddenly I wasn't, which is a strange kind of grief. I've made peace with it by deciding the job is judgement now: what to build, what to reject, and what counts as finished.

The honest version: I'm still a backend developer. I just stopped being limited to what my own hands could write.

My loop is the same, minus the parking stop:

```text
spec  →  plan  →  build  →  check  →  ship
```

You can skip `check`. You'll just be the one explaining the parking stop to your boss.
