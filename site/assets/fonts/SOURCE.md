# Where this font came from

Google Sans, official distribution, SIL Open Font License 1.1.

- Source: https://github.com/google/fonts/tree/main/ofl/googlesans
- File fetched: `GoogleSans[GRAD,opsz,wght].ttf`, blob `a5e76cc713206f1cfe9a7fc31cc1b6f035034d81`
- Licence text: `OFL.txt` in this folder, unmodified.
- Subsetting: `opsz` pinned to 18, `GRAD` pinned to 0, one static instance per weight
  (400, 500, 700), then subset to Basic Latin plus punctuation, arrows and a few symbols.
  `fonttools` and `brotli` did the work; the result is about 37 KB per weight.

These are official Google Fonts assets, not copies of any site's served files.
