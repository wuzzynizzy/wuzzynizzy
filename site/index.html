the short version

I started coding at thirteen because I wanted a Discord bot and nobody was going to write it for me. That turned into years of backend work: schemas, endpoints, auth, queues, migrations at 2am while I watched.

Frontend stayed scary the whole time. I could make a database sing and then spend two hours losing to a centred div, so I stayed where the compiler would tell me when I was wrong.

Then agents got good, and the gap closed faster than I expected. Now I write the spec, an agent writes the code, and I read every line before it ships. I still can't draw, but I can build the whole thing now, and the reading part turned out to be the skill I'd already spent a decade practising.

    what i use

    kiro is where I write the spec, the plan and the tasks before anything gets built. It keeps me from skipping straight to the fun part.

    arena runs the agents, including the one that argued with me about this page. claude is who I argue with about the code.

    wispbyte hosts the bots and the small servers, on the free tier, with the two week login rule that keeps catching me out.

    Google Drive holds the stuff I want a fresh chat to pick up: rules, handoffs, checkpoints. Connectors do the rest. Gmail, Linear, Drive, whatever the task needs, and if a service has an API I will happily spend an evening wiring an agent into it.

    Nobody paid for a single word of this. I like the tools and I'm loud about it.
